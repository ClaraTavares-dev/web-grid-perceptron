# 🤖 Loja de Robô - Perceptron  

O **Loja de Robô** é um projeto em HTML e CSS feito para treinar e mostrar meus avanços, principalmente no uso do **CSS Grid Layout**.  

## ⚙️ Funcionalidades
- Estrutura dos elementos feita com **Grid**, distribuindo imagem e texto em colunas.  
- Exibição do preço em destaque.  
- Botão de compra estilizado com cores.  

## 🛠️ Recursos utilizados com GRID NO CSS
- `display: grid` → organização do layout em colunas.  
- `grid-template-columns` → definição da proporção entre imagem e texto.  
- `gap` → espaçamento entre os elementos do Grid.
